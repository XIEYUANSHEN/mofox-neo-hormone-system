# 赛博内分泌 · Hormone System

> MoFox / Neo-MoFox（KFC）角色情绪内分泌插件：给 AI 角色一套会「累积、衰减、被睡眠修复」的拟真身心状态，而不是每轮失忆。

## 它做什么

六激素状态机：**多巴胺 / 皮质醇 / 催产素 / 血清素 / 内啡肽 / 共情**，基线 50，各按自身半衰期向基线回归。

- 每轮对话的情绪刺激由 LLM 打分（可回退词典），带「位置权重 + 时间衰减」的情绪记忆窗口；
- 疲劳度调制情感增益（越累越难被哄好、也越容易被消耗）；
- 空闲漂移、话题相似度、慢性状态等按配置开关启用；
- 心境以自然语言注入 prompt，**绝不出现数字、绝不出现激素名**（无"多巴胺75"这种出戏表述）。

### v0.2.0：睡眠 ↔ 激素双向耦合

这是本版的主线能力，让"睡觉"成为有生理后果的事件：

1. **睡前情绪决定睡眠质量**——睡前高皮质醇（焦虑）或低血清素/低多巴胺（低落）会抬升失眠概率、拉低睡眠质量分；
2. **睡眠结果回写激素**——坏睡升皮质醇、降多巴胺/血清素/内啡肽；睡饱则把压力/低落拉回基线、补一点催产素与内啡肽、疲劳清零；
3. **梦境与潜意识阴影**——睡坏会留下一段梦境碎片，醒后 24 小时内、且仍处于高压力/低情绪时，会以"潜意识的阴影"自然渗进心境（不主动提、只在气氛安静或被触动时流露）；
4. **起床缓冲（起床气）+ 相位语气**——缺觉/被吵醒会有数轮起床气；睡前犯困、深夜半梦半醒、刚睡醒迷糊各有对应语气；
5. 睡眠按 MoFox 的**墙钟作息**自动结算，无需外部"去睡 N 小时"指令；关掉开关即完全退回旧行为。

睡眠时长由"上次互动 → 现在"落在 `[就寝, 起床]` 窗口的重叠推算，因此夜里沉默过夜、清晨第一次来消息时结算最自然；整晚持续聊天走的是"被吵醒（night_wake）"分支，逻辑独立。

## 安装

二选一（同名时**文件夹优先于 .mfp**，改文件夹版即刻生效）：

- 把 `hormone_system/` 整个目录放入运行实例的 `plugins/`；
- 或投放打包好的 `hormone_system-0.2.0.mfp`。

## 配置

`config/plugins/hormone_system/config.toml`。睡眠相关节：

```toml
[sleep]
enabled = true
bedtime = 23.5          # 就寝（23:30）
wake_time = 7.0         # 起床（07:00）
wind_down_hours = 1.5   # 睡前多久开始犯困
groggy_hours = 1.0      # 起床后多久算刚睡醒
shadow_window_hours = 24.0  # 潜意识阴影可残留多久（小时）
```

`enabled = false` 时睡眠对数值、prompt、相位全部无影响，行为与旧版逐条一致。质量/阴影阈值等参数见 `hormone.py` 模块常量，可进一步提为配置。

## 依赖

- 框架：KFC / `kokoro_flow_chatter`（`manifest.json` 声明）；`min_core_version = 1.3.0-alpha.0`。
- 打分默认跟随角色对话模型，也可在 `[score] model_task` 指定独立模型任务。
